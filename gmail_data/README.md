Place your Gmail OAuth2 credentials file here:

  credentials.json   ←  Download from Google Cloud Console
                        APIs & Services → Credentials → OAuth 2.0 Client ID
                        (Desktop App) → Download JSON → rename to credentials.json

After first login, JARVIS saves:
  token.pickle       ←  Auto-created, do not share or commit to git

Steps:
  1. https://console.cloud.google.com → New Project
  2. Enable Gmail API
  3. Create OAuth 2.0 Client ID (Desktop app)
  4. Download JSON → save as credentials.json in THIS folder
  5. JARVIS Settings → Gmail → Connect Gmail
